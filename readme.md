A collection of **OTClient scripts** focused on automation, bots, macros, and useful utilities to enhance the gameplay experience.

This repository will serve as a place to develop, organize, and share scripts for **OTClient / OTClientV8**, including automation tools, macros, and other useful utilities.

## 📂 Content

Scripts will be added to the repository progressively and organized according to their functionality.

Each script will eventually include a brief description, configuration information, and usage instructions when necessary.

## ⚙️ Compatibility

The scripts are primarily intended for **OTClient**, especially **OTClientV8** and compatible forks.

Compatibility may vary depending on the OTClient version or fork being used.
